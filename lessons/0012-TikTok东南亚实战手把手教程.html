30 天跑通东南亚第一单

约 35 分钟 ｜ 关联 TikTok 跨境实战速查卡 ｜ 利润核算速查卡

这一课不讲泛泛的“东南亚有机会”,而是把 TikTok Shop 东南亚拆成一条 30 天执行线:选国家 → 备资质 → 选品定价 → Listing 本地化 → 内容/达人测试 → 履约售后 → 数据复盘。目标不是马上做大,而是用最少预算验证一件事:你的产品能不能被当地用户看见、点进、下单、签收、给好评。

先定边界:东南亚各站点的开放类目、佣金、税费、认证、物流方案和跨境入驻资格会调整。不要抄网上旧表格。每一步涉及政策、费率、认证、时效时,以 TikTok Shop 官方学习中心 和卖家后台当前提示为准。本课负责给你可执行流程、判断标准和避坑清单。

一、东南亚适合谁做?

你的情况建议原因
会拍短视频 / 直播优先做TikTok Shop 的核心流量来自内容,内容能力比运营技巧更值钱。
有轻小、可演示、低客单货盘优先做东南亚用户对价格敏感,轻小件物流成本和退货损失更可控。
只想上架等自然单不建议没有内容和达人分发,新链接很难持续曝光。
做大件、高值、强认证品先别做物流、售后、认证和资金占用都会放大风险。

新手成功标准

  • 30 天内:完成 1 个站点、3 个 SKU、10 条有效视频、10 个达人建联。
  • 60 天内:拿到 20-50 单真实订单,验证签收率和复购/好评。
  • 90 天内:找到 1 个“可持续盈利 SKU + 1 条稳定内容打法”,再谈扩品。

二、第 0 步:只选一个国家,不要一上来做六国

东南亚不是一个市场,而是 6 套语言、税费、支付习惯和履约规则。第一轮只选一个站点,跑通后再复制。

站点语言/运营适合谁特别注意
马来西亚英文/中文可用度较高中文或英文团队首选多民族、多语言,宗教和节令营销要本地化。
新加坡英文为主客单价较高、售后标准高的品用户对品质、品牌和时效要求高。
泰国泰语有本地翻译/泰国达人短视频氛围强,但素材不能只翻译中文。
越南越南语有越南语运营价格敏感,物流和签收管理要细。
菲律宾英语为主英文素材团队岛屿物流和妥投时效要重点核验。
印尼印尼语 + 本地合规有本地主体/本地仓/本地服务商市场规模大,但监管和平台合作模式变化多,先确认你所在类目是否可做。

选国评分卡(每项 1-5 分)

  1. 语言能力:能不能写出本地人自然的标题、评论回复和售后话术?
  2. 货盘匹配:价格带、规格、电压、尺码、口味、包装是否符合当地?
  3. 物流成本:首重、续重、退件成本是否会吃掉毛利?
  4. 合规难度:类目是否需要认证、标签、本地责任人或特殊资质?
  5. 内容资源:能不能找到 20 个同语言达人或做本地化脚本?
选择规则:总分 ≥ 20 且没有单项 ≤ 2,才进入开店;否则先补能力或换站点。不要因为“市场大”就选最难合规的站点。

三、第 1-3 天:资质与开店检查

3.1 准备材料

  • 营业执照 / 平台认可的经营主体资料
  • 法定代表人或受益人身份材料
  • 对公收款账户或平台支持的第三方收款账户
  • 店铺名、类目、退货仓/发货仓地址
  • 品牌授权书或品牌备案材料(如售品牌品)
  • 类目资质:检测报告、认证、成分表、标签等
  • 供应商发票/采购凭证,避免侵权和假货风险
不要买店、租店、共用收款主体。主体混乱会在审核、提现、售后和违规申诉时互相拖累。宁可慢一周,也要用你可控的合规主体。

3.2 入驻操作线

  1. 打开 TikTok Shop 卖家中心,选择目标市场与“跨境卖家”入口。
  2. 按后台清单上传主体、法人、收款、仓库、类目资质。
  3. 填写店铺名:品牌 + 品类 + 信任词,避免“最低价”“官方”等夸大词。
  4. 绑定收款与结算货币,截图保存费率、结算周期、退款规则。
  5. 开通子账号:运营、客服、发货分开,方便追责。
  6. 进入“规则中心/类目管理”,确认你的 SKU 是否可售、是否需资质。

3.3 审核期不等待

审核期间做三件事:联系 3 家物流商要报价、准备 20 个达人名单、让供应商寄样品。不要等店铺下来才开始选品。

四、第 4-7 天:选 3 个测试 SKU,先算利润再上架

4.1 东南亚选品四条硬标准

标准做法红线
看得懂 3 秒产品能一眼演示痛点或效果需要长解释的产品先放弃
拿得住价格本地零售价处于该站点常见价格带运费/佣金后无毛利
售后少不易碎、不含复杂电子、尺码风险低高退货率吞掉利润
合规轻不用食品、药品、化妆品等高监管品起步无认证先上架

4.2 起步品类方向

  • 家居收纳:可演示前后对比,客单低,用户容易冲动下单。
  • 手机配件:轻小、通用性强,但竞争激烈,必须打差异卖点。
  • 厨房小工具:场景视频强,适合达人拍摄。
  • 汽车/摩托配件:东南亚摩托车场景多,但要确认适配车型。
  • 运动收纳/旅行收纳:轻小、价格友好,便于内容系列化。
新手第一批别碰:食品、保健品、药品、婴幼儿用品、化妆品、成人用品、电子烟、强认证电器、大件家具。不是不能做,而是不适合第一轮跑通。

4.3 单位经济模型

到手收入 = 商品售价 - 平台佣金 - 支付/交易费 - 促销折扣
利润 = 到手收入 - 采购成本 - 国内运费 - 跨境物流 - 尾程/仓配
      - 包装费 - 退货损失 - 达人佣金 - 广告费 - 汇兑损失 - 退款赔付

最低毛利率建议: ≥ 45%
单件最低目标净利: ≥ 8%-15%(有广告时先保证广告前利润为正)

4.4 定价表模板

项目你的数校验
当地售价________对齐同类热卖价
平台费用________后台按类目实时查
采购 + 包装________含快递和耗材
跨境物流________按实际重量体积重取高
达人/广告分摊________先按 10%-15% 预留
退货/破损预留________轻小件至少 3%-5%
净利________< 8% 就重定价或换品

五、第 8-12 天:Listing 本地化,不做机器翻译

5.1 五模块清单

  • 标题:核心词 + 使用场景 + 规格 + 适配范围,不堆无关热词。
  • 主图:第一张讲清“是什么、解决什么”;第二张讲尺寸/用法。
  • 视频:前 3 秒展示痛点,不要品牌片。
  • 规格:颜色、尺码、电压、插头、适配车型、包装数量写清。
  • 售后:发货时效、退换范围、客服语言、节假日说明。

5.2 本地化检查

项目错误做法正确做法
语言中文直译 / 英文机翻找当地用户或 native speaker 润色
货币全部折美元使用当地货币和心理价位
单位只写 cm、kg、USD兼顾当地常用单位和货币
节令复制欧美日历按当地节日、雨季、开学季、发薪日排品
图纹使用不熟悉符号/手势让本地达人或服务商审图

5.3 上架前最后检查

  • 标题没有“最佳”“治愈”“100%有效”等违规词。
  • 图片没有未授权明星、平台 logo、他人测评。
  • 类目、品牌、规格、条码填写正确。
  • 库存真实,不是“先卖后找货”。
  • 后台物流模板和运费模板可用。
  • 至少 3 个 SKU 有差异:低价引流款、主推款、利润款。

六、第 13-19 天:内容和达人双轨测试

6.1 官方账号内容

官方号的作用是承接店铺信任和持续测素材,不是每天发广告。每个 SKU 做 3 个角度:

角度脚本结构适合产品
痛点对比混乱场景 → 产品使用 → 结果收纳、清洁、厨房工具
过程展示开箱 → 安装 → 30 秒效果配件、运动用品
场景合集3 个生活场景重复出现同一痛点旅行、家居、小工具

15 秒脚本模板

0-3 秒:展示真实混乱/痛点画面 + 一句本地语言提问
3-7 秒:产品出现,快速演示怎么解决
7-12 秒:展示细节、尺寸、稳定性、使用结果
12-15 秒:行动指令:点击购物车/查看规格/评论区提问

每天发布节奏

  1. 每个主推 SKU 每天 1-2 条,不同开头。
  2. 前 5 条只优化前 3 秒,不追求精致。
  3. 用当地语言字幕,不要只放中英文。
  4. 评论区 2 小时内回复,把常见问题补进 Listing。
  5. 每条视频记录:开头、场景、卖点、时长、购物车点击、成交。

6.2 达人建联

新店铺最有效的加速器是本地达人。第一轮不要只追头部,优先找 1 万-10 万粉、近 30 天有带货视频、画面稳定的达人。

每天建联 SOP

  1. 筛 20 个达人:同语言、同品类、近 30 天有更新。
  2. 剔除:只发图文、评论区无人回复、链接挂错、数据异常。
  3. 发送短消息:产品卖点 + 适合人群 + 合作方式 + 样品价值。
  4. 跟踪 3 天:没回复只跟进 1 次,不刷屏。
  5. 寄样前确认地址、佣金、内容要求、发布时间。

英文私信模板

Hi [Name], I really liked your video about [specific topic].

We are launching [product] for [audience]. It solves [pain point]
and works well for a 15-30s demo video.

Would you like to try a free sample? Commission: [X]%.
No pressure to post if you don't like the product.
达人测试目标:建联 50 个 → 回复 15 个 → 寄样 8-10 个 → 出片 3-5 条。不要把预算押在 1 个达人身上。

七、第 20-25 天:履约、客服和售后

7.1 物流方案选择

方案适合检查项
平台推荐/认证物流新手首选轨迹、时效、丢赔、禁运、退货仓
跨境仓储 + 尾程日单稳定后库存周转、补货周期、盘点差异
自找低价专线谨慎必须查轨迹率、签收率、丢件赔付

7.2 发货 SOP

  • 订单生成后当天或次日打印面单,不要压单。
  • 每个 SKU 有固定称重记录,防止运费偏差。
  • 易碎品做跌落测试,包装先寄自己一版。
  • 上传正确跟踪号,不使用无关单号。
  • 每天看“待发货/超时/异常/退款”四个看板。
  • 缺货时第一时间下架或限购,不赌补货速度。

7.3 客服话术原则

场景坏回复好回复
物流慢请等待给出预计时间、当前节点、可跟进入口
尺寸不适配用户自己看错致歉 + 核对页面 + 给退换方案
质量投诉只退款息事宁人要照片/视频,记录批次,反馈供应商
差评公开争吵私下解决,页面用事实补充说明

八、第 26-30 天:数据复盘与放量决策

8.1 每周看板

指标看什么动作
视频播放前 3 秒是否被划走换开头,不急着换产品
商品点击率视频与购物车是否相关改口播、主图、价格锚点
下单转化率Listing 是否讲清规格补图、补 FAQ、清风险词
签收率物流和服务商稳定性对比渠道,暂停低质线路
退款率质量、描述、破损先分原因,再谈降价
单件净利是否扛得住广告负毛利不扩量

8.2 放量决策树

是否有 20 单以上?
├─ 否 → 检查:曝光是否够?达人是否出片?Listing 是否清楚?
└─ 是 → 退款率是否可接受?
    ├─ 否 → 停放量,先修质量/描述/物流
    └─ 是 → 单件广告前利润是否 > 0?
        ├─ 否 → 重定价、换包装、换供应商
        └─ 是 → 复制 Top 3 素材,小预算投广告

8.3 第二个月节奏

  1. 保留 Top 3 视频,做同开头、同结构、换场景。
  2. 维护 10 个出过好内容的达人,建立长期佣金。
  3. 把 FAQ 写进 Listing,减少重复客服。
  4. 补 2 个同场景 SKU,形成关联购买。
  5. 日单稳定后再备货到海外仓,不要提前压库存。

九、新手最常犯的 8 个错误

  1. 六国一起开:语言、物流、合规全乱。先一个站点跑通。
  2. 只看销量不看利润:佣金、物流、退货、达人佣金一扣就亏。
  3. 机器翻译 Listing:用户看不懂规格,退货率飙升。
  4. 素材只讲品牌:前三秒没有痛点和效果,直接划走。
  5. 达人只找头部:贵、慢、不配合;中小达人更容易测试。
  6. 无库存先卖:超时发货会伤店铺指标。
  7. 忽视认证标签:下架、扣分、罚款比不出单更贵。
  8. 负毛利投广告:广告只能放大有效供给,不能拯救亏损品。

本课收获

你能用 30 天完成一次小规模、可复盘的 TikTok Shop 东南亚测试:选定站点、合规开店、算清利润、做本地化 Listing、用内容和达人拿曝光、稳住履约售后,并用数据判断该停、该修还是放量。

小测一下

第一次做 TikTok Shop 东南亚,最合理的策略是什么?
答案:b。东南亚不是统一市场。先在一个站点验证选品、内容、履约和利润,再复制到其他站点,成功率更高。
视频有播放但商品点击低,优先优化什么?
答案:c。有播放说明内容能被推荐,点击低通常是开头吸引的人群与商品不匹配,或没有明确引导。先修素材和承接,再考虑广告。
什么时候可以开始放量?
答案:a。放量必须同时满足供给稳定、履约稳定、利润为正。播放量只是前端信号,不等于可盈利生意。
