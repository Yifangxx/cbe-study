把广告费花在刀刃上

约 20 分钟 ｜ 关联 广告数据速查卡 ｜ TikTok 跨境实战

第 6 课你学了亚马逊站内 PPC 基础。这一课进阶:① 多平台广告(Facebook/TikTok/Google)的投放逻辑 ② 扩规模(scaling)的方法 ③ 用数据精准优化,把每一分钱花出最大效果。广告是跨境生意的放大器——掌握它,销量能翻 5-10 倍。

一、三大广告平台对比

平台逻辑适合特点
Facebook/IG Ads兴趣定向(推)冲动消费、视觉系产品素材为王,爆款制造机
TikTok Ads兴趣+算法(推)年轻群体、新奇特红利期,CPM 低,起量快
Google Ads搜索意图(拉)有明确需求的功能品转化精准,但 CPC 高
Amazon PPC(站内)购买意图(拉)已在亚马逊的买家转化最高,第 6 课已学
选平台看产品属性。视觉冲击强、激发冲动购买的(美妆、家居好物、新奇特)→ Facebook/TikTok。有明确功能需求、会被主动搜索的(工具、配件、专业品)→ Google。先选一个深耕,别贪多。

二、Facebook 广告实战

账户结构(三层)

广告系列 (Campaign)  ← 设目标(转化/流量)
  └─ 广告组 (Ad Set)  ← 设受众、预算、版位
       └─ 广告 (Ad)   ← 设素材(视频/图片+文案)

新手投放流程

  1. 装 Pixel:在 Shopify/独立站装 Facebook Pixel(追踪转化必需)
  2. 选目标:Conversions(转化)——不要选 Traffic,要的是订单不是点击
  3. 建受众:Broad(宽泛)+ Interest(兴趣)各试一个
  4. 预算:每个广告组 $20-50/天,至少跑 3-4 天
  5. 做素材:3-5 个不同角度的视频/图片(A/B 测试)
  6. 看数据:CPM、CTR、CPC、CPA(每单成本),关停差的

素材是 Facebook 广告的灵魂

素材类型效果制作
UGC 风格视频最佳,像真人分享手机自拍+真实使用
产品展示视频好,直观展示功能实拍+字幕解说
前后对比强,制造冲击使用前后画面剪辑
纯图片弱,慎用仅作补充测试
Facebook 广告 80% 看素材。同样的人群、预算,好素材 CPA $15,差素材 CPA $50+。持续做新素材是 Facebook 投放的核心动作,一个爆款素材能烧几万刀不衰减。

三、TikTok 广告实战

为什么 TikTok 广告值得做

  • CPM 低:比 Facebook 便宜 30-50%(红利期)
  • 算法强:不需要精准定向,算法自动找人
  • 素材门槛低:原生感视频(不像广告)效果最好

TikTok 广告素材铁律

  • 前 3 秒抓人:不然划走(TikTok 用户耐心极低)
  • 原生感:像普通 TikTok 视频,不像广告
  • 竖屏 9:16:横屏直接废
  • 带字幕:很多人静音刷,字幕必需
  • 引导行动:结尾明确"主页链接"/"立即购买"

Spark Ads(原生广告)

把已有的 TikTok 有机视频(你发的或达人发的)推成广告,比普通广告信任度高 2-3 倍。先让视频自然爆,再用 Spark Ads 放大,是最高效打法。

四、扩规模(Scaling)策略

找到盈利的广告组后,如何放大?有三种方法:

方法怎么做风险
垂直扩(加预算)盈利广告组每天加 20-30% 预算低,推荐新手
水平扩(复制组)复制盈利组,换受众或素材中,需测试
受众扩(LAL)基于买家数据建 Lookalike需 100+ 买家数据
扩规模最大的坑:加预算太快。一次性把 $20 广告组加到 $200,算法会重新学习,CPA 暴涨。每天加 20-30%,给算法适应时间。稳扎稳打比激进扩张活得久。

五、关键数据指标详解

指标含义健康值诊断
CPM千次展示成本FB $5-15 / TT $2-8太高→素材差或受众太窄
CTR点击率> 1.5%低→素材不吸引
CPC每次点击成本< $1高→素材差或竞争激烈
CPA每单获客成本< 毛利的 40%核心指标,决定盈利
ROAS广告投资回报> 2.0(即 200%)<2 亏本,>3 健康

盈利公式

ROAS = 售价 / (产品成本 + 广告CPA + 运费)
售价 $30,成本 $8,运费 $5,CPA $12
ROAS = 30 / (8+5+12) = 30/25 = 1.2 ❌ 亏本

要 ROAS>2,需降 CPA 或提售价

六、广告优化决策树

CPA 太高(亏本)?
├─ CTR 低(<1.5%)?
│   ├─ 素材不行 → 做新素材(最常见原因)
│   └─ 受众太宽 → 收窄兴趣定向
├─ CTR 够但 CVR 低?
│   ├─ 落地页差 → 优化产品页/加评论
│   ├─ 价格高 → 降价或加促销
│   └─ 运费贵 → 包邮或藏运费
└─ CPM 太高?
    ├─ 受众太窄 → 放宽
    └─ 素材相关度低 → 换更原生素材

七、再营销(Retargeting)

看过你广告/访问过网站但没买的人,是最容易转化的。用再营销追投:

  • 弃单挽回:加购未付款,邮件+广告追投(挽回率 10-30%)
  • 浏览追投:看过产品页的人,给优惠券再触达
  • 老客复购:买过的人推新品/补充装
再营销 ROI 最高。冷流量获客 CPA $15,再营销 CPA 只要 $3-5。独立站必须做 Klaviyo 弃单邮件 + Facebook 再营销广告,这部分流量是"捡回来的钱"。

八、广告素材库(持续产出)

素材会疲劳(ad fatigue),一个素材 3-7 天效果就会下降。必须持续产出:

  • UGC 平台:Insense、Billo,付费找创作者拍真实使用视频($30-100/条)
  • 自己拍:手机+样品,真实场景,成本低
  • AI 生成:ChatGPT 写脚本 + 剪映/CapCut 合成
  • 竞品借鉴:Facebook Ad Library 看同行爆款素材
本课收获

你懂三大广告平台的逻辑和选择,会投 Facebook/TikTok 广告并制作高转化素材,会用 ROAS/CPA 判断盈利,会扩规模(垂直/水平/受众),懂再营销和持续产出素材。现在你能把广告从"烧钱"变成"赚钱机器"。

小测一下

Facebook 广告 CPA 太高,首先查什么?
答案:a。CPA 高要先定位原因:CTR 低=素材不行(最常见),CVR 低=落地页/价格问题,CPM 高=受众或竞争问题。用决策树逐层排查,别盲目加预算或一刀切关闭。素材是 Facebook 广告 80% 的变量。
盈利广告组从 $20/天扩到 $200,怎么扩?
答案:b。一次性大幅加预算会让算法重新进入学习期,CPA 暴涨甚至翻倍。正确做法是每天加 20-30%,给算法数据适应时间。稳扎稳打,ROAS 才能稳住。
