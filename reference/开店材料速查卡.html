二、亚马逊开店必备材料

材料要求注意事项
营业执照有效期内,经营范围与所售品类相关个人无法开店,必须企业资质
法人身份证正反面清晰照片 / 扫描件四角完整、无遮挡、无反光
双币信用卡Visa 或 MasterCard,可用于国际支付用于扣月租与广告费,额度建议 ≥ 月花费 2 倍
收款账户Payoneer 或 PingPong用于接收外币并结汇回国内
公共事业账单水电 / 煤气 / 网络账单,地址须一致见下方地址一致性警告
专用邮箱 + 手机全新、未被任何亚马逊账号使用过一台电脑一个 IP 一个账号,防关联

三、账单地址一致性警告

营业执照地址 = 账单地址。两者必须完全一致(连标点、门牌号写法都要对得上),否则 KYC 审核会被拒。建议提交水电煤账单前,逐字核对地址字段。

七、合规速查

知识产权

  • 上架前查美国商标:USPTO tmsearch.uspto.gov
  • 商标、专利、版权任一被占都不要碰,侵权会封号

品类认证

品类认证要求
电子产品美国 FCC、欧洲 CE
玩具美国 ASTM、欧洲 EN71
食品 / 保健品美国 FDA
普通家居 / 日用通常无需特殊认证

税务

  • 美国:销售额超过各州阈值时由平台代缴,操作相对简单
  • 欧洲:必须注册 VAT(增值税),否则货物无法清关入仓
